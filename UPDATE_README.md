## 🚀 **Quick Start**

### **1. Try the Demo**
```bash
git clone https://github.com/yourusername/curable-labs-trial-by-molecule
cd curable-labs-trial-by-molecule
npm install
npm start
```

Visit `http://localhost:7000` and:
1. Select **🧠 Tozadenant** from dropdown
2. Click **🎬 Begin Competition Audition**
3. Watch the ANT scoring modal
4. Continue through Lane 2 and Lane 3

### **2. Deploy to Aptos**
```bash
# Install Aptos CLI
# Follow: https://aptos.dev/cli-tools/aptos-cli-tool/install-aptos-cli

# Deploy contracts
aptos move compile
aptos move publish --named-addresses ant_scoring=default
```
