🧪 Testing Guide

Follow these steps to test the ANT Scoring System

📱 1. SETUP (2 minutes)

1

Install MetaMask

Download from metamask.io

2

Switch to Sepolia Testnet

In MetaMask: Networks → Show test networks → Select Sepolia

3

Get Test ETH

Free test ETH: sepoliafaucet.com

4

Connect Your Wallet

Click "Connect Wallet" at the top of this page

🔬 2. TEST AS RESEARCHER

1

Submit a Proposal

Go to "Submit Proposal" → Fill form → Click Submit

2

Confirm Transaction

Approve in MetaMask → Wait ~15 seconds for confirmation

3

Check Your Profile

Go to "My Profile" → See your proposal and stats

⭐ 3. TEST AS SCORER

1

View Proposals

Go to "Score Proposals" → Browse active research

2

Review Research

Click "View Full Details" to read proposal & IPFS link

3

Submit Score

Rate 5 criteria (1-5 stars) → Submit → Confirm transaction

4

Check Stats

Go to "My Profile" → See scoring activity

⚙️ 4. TEST AS ADMIN

1

Access Dashboard

Go to "Admin" → View system stats

2

Manage Scorers

Add/remove authorized scorers using wallet addresses

3

Update Settings

Adjust passing threshold or view all proposals
