# 🤝 Contributing to America's Next Top CurAble

Thank you for your interest in contributing! This guide will help you get started.

## 🚀 Quick Start

1. **Fork the repository**
2. **Clone your fork:**
   ```bash
   git clone https://github.com/[your-username]/americas-next-top-curable.git
   cd americas-next-top-curable
   ```
3. **Create a feature branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes**
5. **Test thoroughly**
6. **Submit a pull request**

## 🎯 How to Contribute

### 🐛 Bug Reports
Found a bug? Please create an issue with:
- **Clear description** of the problem
- **Steps to reproduce** the issue
- **Expected vs actual behavior**
- **Browser/OS information**
- **Screenshots** if helpful

### ✨ Feature Requests
Have an idea? We'd love to hear it! Include:
- **Use case** description
- **Expected behavior**
- **Why this would be valuable**
- **Implementation suggestions** (optional)

### 🔧 Code Contributions

#### Areas We Need Help:
- **🧬 Molecular Data:** Adding real molecular databases
- **🎨 UI/UX:** Design improvements and animations
- **⛓️ Blockchain:** Smart contract optimizations
- **📱 Mobile:** Responsive design enhancements
- **🔍 Testing:** Automated testing and validation
- **📚 Documentation:** Guides and tutorials

## 📋 Development Guidelines

### Code Style
- **JavaScript:** Use modern ES6+ syntax
- **HTML:** Semantic, accessible markup
- **CSS:** Follow existing design patterns
- **Comments:** Explain complex logic
- **Functions:** Keep them focused and small

### File Organization
```
americas-next-top-curable/
├── 🎯 DEMO FILES (main functionality)
├── ⛓️ BLOCKCHAIN (smart contracts)
├── 🖥️ SERVER (local development)
├── 📚 DOCUMENTATION
└── 🧪 EXAMPLES & TESTS
```

### Testing
Before submitting:
- [ ] Test all demo flows
- [ ] Check mobile responsiveness
- [ ] Verify browser compatibility
- [ ] Test blockchain integration
- [ ] Validate error handling

## 🔧 Technical Areas

### Frontend Development
- **No frameworks** - Keep it simple and compatible
- **Progressive enhancement** - Core functionality first
- **Accessibility** - WCAG 2.1 AA compliance
- **Performance** - Optimize for fast loading

### Blockchain Development
- **Move language** for smart contracts
- **Aptos ecosystem** standards
- **Gas optimization** for cost efficiency
- **Security** best practices

### Documentation
- **Clear examples** with code snippets
- **Screenshots** for visual features
- **Step-by-step** guides
- **Multiple skill levels** (beginner to advanced)

## 🎨 Design Principles

### User Experience
- **Zero learning curve** - Intuitive interface
- **Immediate feedback** - Visual responses to actions
- **Error forgiveness** - Helpful error messages
- **Progressive disclosure** - Show information when needed

### Visual Design  
- **Dark theme** with glassmorphic elements
- **Consistent spacing** and typography
- **Smooth animations** and transitions
- **Mobile-first** responsive design

## 🧪 Adding New Features

### New Molecular Examples
```javascript
const newMolecule = {
    name: 'Your Molecule Name',
    smile: 'SMILE_NOTATION_HERE',
    description: 'Brief therapeutic description',
    category: 'therapeutic_area'
};
```

### New Scoring Components
```javascript
const newComponent = {
    id: 'component_id',
    name: 'Component Name', 
    weight: 0.1,  // 10%
    base: 75,     // Base score
    description: 'What this component measures'
};
```

### New Demo Flows
Follow the existing pattern:
1. **Lane 1:** Validation/Scoring
2. **Lane 2:** Community building
3. **Lane 3:** Marketplace/Trading

## 📝 Pull Request Process

### Before Submitting:
1. **Update documentation** if needed
2. **Add tests** for new features
3. **Check code style** consistency  
4. **Test across browsers**
5. **Update README** if needed

### PR Template:
```markdown
## Description
Brief description of changes

## Type of Change
- [ ] Bug fix
- [ ] New feature
- [ ] Documentation update
- [ ] Performance improvement

## Testing
- [ ] Tested locally
- [ ] Cross-browser testing
- [ ] Mobile testing
- [ ] Blockchain testing (if applicable)

## Screenshots
Include before/after if visual changes
```

## 🌟 Recognition

Contributors will be:
- **Listed in README** acknowledgments
- **Tagged in releases** for their contributions
- **Invited to discussions** about project direction
- **Given credit** in documentation

## 📞 Getting Help

### Discussion Channels:
- **GitHub Discussions** - General questions
- **Issues** - Bug reports and feature requests
- **Pull Requests** - Code review and feedback

### Response Times:
- **Issues:** Within 48 hours
- **Pull Requests:** Within 1 week
- **Discussions:** Within 24 hours

## 🎯 Project Priorities

### Current Focus:
1. **Stability** - Bug fixes and reliability
2. **Documentation** - Clear guides and examples
3. **Accessibility** - Universal usability
4. **Performance** - Fast, smooth experience

### Future Goals:
1. **Real Data** - Actual molecular databases
2. **Advanced Scoring** - ML-powered algorithms  
3. **Community Features** - User accounts and profiles
4. **Mobile App** - Native mobile experience

## 📄 License

By contributing, you agree that your contributions will be licensed under the same MIT License that covers the project.

## 🙏 Thank You!

Every contribution helps make molecular discovery more accessible and engaging. Whether you're fixing a typo or adding a major feature, your effort is appreciated!
